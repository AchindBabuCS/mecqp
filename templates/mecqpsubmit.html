Upload and submit PYQPs of your own.

The upload PYQP will then checked and verified by the admin and may be accepted and added into the collection of papers or will be rejected.

If rejected, reason for rejection will be provided.

After submission, you will be provided a submission ID which you must remember to check the status of your submission.

Upload Rules:

  1. File must be in PDF format
  2. Must not contain any personal information
  3. File must be under 10MB size
  4. Description must contain the following details:
    • Scheme (eg: 2024, etc)
    • Branch (eg: CSE, EC, etc)
    • Semester (eg: 1,2,etc)
    • Exam Type (eg: Internal-1, Semester-R, etc)
    • Month (eg: January, February, etc)
    • Year (eg: 2026, 2025, etc)
    • Subject Code (eg: GAMAT101, GAMAT201, etc)
    • Subject (eg: Mathematics For Information Science-1, Discrete Mathematics, etc )
  5. Description must contain any corrections to QP or notes for the end user, if any exist.
  6. PDF must contain clear and full scans of QP
  7. Only PYQP PDFs must be uploaded.

Potential reasons for rejection:

  • File contains personal information
  • Description does not contain adequate details
  • File contains blurred scans
  • File is incomplete QP
  • File does not contain QP

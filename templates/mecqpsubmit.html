Submit

Upload and submit PYQPs of your own. The upload PYQP will then checked and verified by the admin and may be accepted and added into the collection of papers or will be rejected. If rejected, reason for rejection will be provided. After submission, you will be provided a submission ID which you must remember to check the status of your submission.

Upload Rules:

  1. File must be in PDF format
  2. Must not contain any personal information
  3. File must be under 10MB size
  4. Description must contain the following details:
    • Scheme (eg: 2024, etc)
    • Branch (eg: CSE, EC, etc)
    • Semester (eg: 1,2,etc)
    • Exam Type (eg: Internal-1, Semester-R, etc)
    • Month (eg: January, February, etc)
    • Year (eg: 2026, 2025, etc)
    • Subject Code (eg: GAMAT101, GAMAT201, etc)
    • Subject (eg: Mathematics For Information Science-1, Discrete Mathematics, etc )
  5. Description must contain any corrections to QP or notes for the end user, if any exist.
  6. PDF must contain clear and full scans of QP
  7. Only PYQP PDFs must be uploaded.
  8. Do not intentionally alter, fabricate, or manipulate the contents of a question paper. If a paper has unavoidable scan defects or known corrections, mention them in the description.
  9. Do not submit files containing content unrelated to the question paper. For example, advertisements, promotional material, unrelated documents, etc.
  10. Do not submit the same paper multiple times unless the new submission is a clearer or more complete version of a paper already present in MecQP.
  11. The information provided in the description must be accurate to the best of the uploader's knowledge.
  12. Submitting a paper does not guarantee that it will be added to MecQP. All submissions are subject to review and verification by the administrator.
  13. MecQP may reject or remove a submission if it does not comply with these rules or if there is a concern regarding its authenticity, legality, copyright, privacy, or suitability for the repository.

Potential reasons for rejection:

  • File contains personal information
  • Description does not contain adequate details
  • File contains blurred scans
  • File is incomplete QP
  • File does not contain QP
  • Paper is intentionally altered, fabricated, or manipulated
  • Submission contains unrelated material
  • Paper is already present in MecQP, unless the submission provides a substantially clearer or more complete version
  • Description contains inaccurate or misleading information
  • Submission fails administrator verification
